# QUEEN ♡ QUINCY — A Love Story Written by Fate 💗

A cinematic, mobile-first romantic web experience: starfield gate, self-writing love letter, memory timeline, "Why Queen Is Special" cards, a full-screen video moment with sound, destiny quote, and a final love scene.

## Run locally
```
npm install   # (no deps — just formality)
npm start     # serves on port 3001
```

## Deploy on Render
1. Render → New → Web Service → connect this repo
2. Runtime: **Node**
3. Build command: `npm install`
4. Start command: `npm start`
That's it. Render auto-detects the port. 💗
